# Olivia LMS — ViciDial Inbound Call Integration Requirements
## Developer Integration Specification

### 1. Objective
Configure ViciDial to send inbound call information to Olivia LMS whenever an inbound call is received. Olivia LMS will use the DID to identify the organization associated with the inbound call and store the caller information.

---

### 2. Webhook Endpoint
**Preferred method — HTTP POST**
* **Endpoint:** `https://olivialms.cloud/api/inbound/call-data`
* **Method:** `POST`
* **Content-Type:** `application/json`

---

### 3. Data Required From ViciDial

| Olivia LMS Field | Required | ViciDial Value / Variable | Description |
|---|---|---|---|
| `phone_number` | **Required** | `--A--phone_number--B--` | Customer's incoming phone number |
| `did` | **Required** | `--A--did_id--B--` | DID number that the customer called |
| `campaign_name` | **Required** | `--A--campaign--B--` | ViciDial campaign / In-Group |
| `agent_id` | Optional | `--A--user--B--` | Agent/user ID answering the call |
| `caller_name` | Optional | `--A--first_name--B-- --A--last_name--B--` | Caller full name, if available |
| `status` | Optional | `--A--dispo--B--` | Call status/disposition; initial value may be `RECEIVED` |

---

### 4. Important Field Distinction
The following distinction is critical:
* `phone_number` = customer's incoming phone number
* `did` = DID number that the customer called

**Example:**
* Customer Phone: `5550001111`
* DID Called: `19162330139`

---

### 5. Expected JSON Payload

```json
{
  "campaign_name": "--A--campaign--B--",
  "did": "--A--did_id--B--",
  "phone_number": "--A--phone_number--B--",
  "agent_id": "--A--user--B--",
  "caller_name": "--A--first_name--B-- --A--last_name--B--",
  "status": "RECEIVED"
}
```

#### Example after ViciDial variable substitution:
```json
{
  "campaign_name": "SALES_INBOUND",
  "did": "19162330139",
  "phone_number": "5550001111",
  "agent_id": "1001",
  "caller_name": "John Smith",
  "status": "RECEIVED"
}
```

---

### 6. Required Fields
At minimum, the webhook request must contain:
* `phone_number`
* `did`
* `campaign_name`

The ViciDial integration should ensure these values are populated correctly before sending the request. Optional fields may be omitted when unavailable.

---

### 7. Expected Inbound Call Flow
```text
Customer calls → ViciDial receives inbound call → ViciDial collects caller phone, DID, campaign/In-Group, agent ID, caller name and status → ViciDial sends HTTP request → Olivia LMS receives data → DID is mapped to organization → inbound record is created.
```

---

### 8. GET / URL Trigger — Alternative
If the ViciDial configuration requires a URL/Web Form trigger instead of POST, use:
```text
https://olivialms.cloud/api/inbound/call-data?campaign_name=--A--campaign--B--&did=--A--did_id--B--&phone_number=--A--phone_number--B--&agent_id=--A--user--B--&caller_name=--A--first_name--B--+--A--last_name--B--&status=RECEIVED
```
Dynamic values must be URL-encoded where required.

---

### 9. Expected Response
Successful processing returns HTTP `200 OK`.
```json
{
  "success": true,
  "message": "Inbound call recorded successfully",
  "id": "6aa25f66e264217c5e294e9e",
  "organization": "Social Up Media LLC",
  "did": "19162330139"
}
```

---

### 10. Error Response
If required information is missing or invalid, the API may return HTTP `400 Bad Request`.
```json
{
  "success": false,
  "message": "At least phone_number or did is required."
}
```
Please log failed webhook requests on the ViciDial side for troubleshooting.

---

### 11. Testing
Before enabling the integration for production traffic, perform a test using:

| Field | Test Value |
|---|---|
| DID | `19162330139` |
| Phone Number | `5550001111` |
| Campaign | `TEST - INBOUND CAMPAIGN` |
| Caller Name | `TEST - Inbound Caller` |
| Status | `RECEIVED` |

#### Expected Test Payload:
```json
{
  "campaign_name": "TEST - INBOUND CAMPAIGN",
  "did": "19162330139",
  "phone_number": "5550001111",
  "caller_name": "TEST - Inbound Caller",
  "status": "RECEIVED"
}
```

---

### 12. ViciDial Developer Checklist
* [ ] Inbound call triggers the webhook.
* [ ] Customer phone number is sent as `phone_number`.
* [ ] Dialed DID is sent as `did`.
* [ ] ViciDial campaign/In-Group is sent as `campaign_name`.
* [ ] Agent ID is sent as `agent_id` when available.
* [ ] Caller name is sent as `caller_name` when available.
* [ ] Initial inbound status is sent as `RECEIVED`.
* [ ] POST request is sent as JSON.
* [ ] Olivia LMS returns HTTP 200.
* [ ] Test inbound call creates a record in Olivia LMS.
* [ ] Correct organization is identified using the DID.

---

### 13. Information Required From ViciDial Developer
1. Confirmation that the webhook has been configured.
2. The ViciDial event/trigger being used.
3. The final payload generated by ViciDial during a real test call.
4. Confirmation that the correct DID is being passed.
5. Confirmation that Olivia LMS returns HTTP 200.
